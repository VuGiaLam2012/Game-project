Mini Tower Defense

Open `index.html` in a browser to play the mini game.

Run a simple local server (recommended) from the folder and open http://localhost:8000:

```bash
python -m http.server 8000
```

Files:
- `index.html` — game UI
- `style.css` — styles
- `main.js` — game logic (not implemented yet)
